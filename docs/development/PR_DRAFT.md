# Phase 0: establish Inkwell engineering foundation

Inkwell needs a reviewed, reproducible foundation before private creative features are introduced. This change establishes the modular pnpm/Next.js workspace, an accessible responsive shell with themes, versioned operational API boundaries, Prisma/local PostgreSQL foundation, Docker runtime, CI, task templates, and the v0.6 product/architecture/security/deployment plan.

Authentication, creative tools, public sharing, hosted resources and deployment are not enabled. Exact validation evidence and known limitations are in PHASE_0_REPORT.md. The initial SQL migration creates only User/Workspace foundations and is guarded for local execution.

Remote issue references and the PR URL remain unassigned while the selected owner's administration access is blocked. This file is a local PR draft, not a published PR. Owner approval is required before merging; no deployment approval is included.
