## Behavior and architecture

ADR-008 compares ranking strategies and chooses one integer sequence with atomic transactional replacement. Existing scenes and source history stay in place. Grouping and active/archive filters are projections of that sequence; root filters include child scenes. Scene numbers remain canonical in both responsive grid and list. No column-derived secondary sequence exists.

Project→Story locking serializes structural writes. Moves compare Story.sequenceVersion and use deferred uniqueness plus parameterized batches of 500. A 605-scene test exercises multiple batches. Scene content/status uses Scene.version independently; movement never overwrites notes or advances their edit version. Structural paging binds position to a sequence revision and rejects stale cursors. Scene create/duplicate append safely to the latest sequence. Invalid targets and commit-time uniqueness failures leave no partial order.

Groups use scoped parent FKs and SQL guards for immutable identity, root/child depth, cycles and same-story ownership. Service and raw-SQL opposing-reparent races are tested. Group archive requires active children/scenes to be moved or archived first. Restore parents/groups before children/scenes. Archive is non-destructive; scenes retain content, sequence membership, groups and references.

Explicit SceneCharacterLink/SceneLocationLink FKs/type guards admit only shared or same-story-local canon from the same project. Displays resolve current story overrides and show archive labels. Canon views expose qualified scene backlinks. Reference changes are incremental, with Scene preconditions for canon links and the existing Idea preconditions for IdeaSceneLink. Scene content edits never replace Idea references. Converted source links remain retained.

Duplication creates new scene/link IDs, appends to the sequence, copies content/status/group and valid references, and records immutable qualified duplicatedFromId. It does not clone IdeaConversion history or mutate the source. Archived linked endpoints remain references with visible labels. Copies are independently editable.
