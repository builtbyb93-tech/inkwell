## Evidence and boundaries

Commands: `pnpm check`; `pnpm typecheck` after final browser-test additions; `pnpm db:validate`; `pnpm test:integration`; `pnpm test:e2e --workers=2`; `pnpm security:secrets`; `pnpm audit --audit-level=high`; `pnpm audit --prod`.

SQL tests cover all save targets, duplicate concurrent requests, original-version replay after unseen edits, authorization and key mismatch rollback; cross-workspace/project/story search, effective inherited/custom/clear canon, archive context and cursor boundaries; full graph/content/overrides/order/copy/source round trip with fresh IDs, classification reuse, unrelated-project exclusion, unsafe archives and late database rollback of every imported table. The benchmark fixture has 100 projects, 500 stories, 3,000 Ideas, 3,000 canon records, 3,000 scenes, 300 groups and 100 overrides.

Browser coverage includes desktop/mobile existing journeys plus in-flight typing, lost-response retry, explicit restore/compare/rebase, seven-day expiry, settings clearing/disable, logout/account separation, unavailable storage, capacity overflow without eviction, pending-encryption purge and successful-capture races, record navigation isolation, search filters, archive download/import preview/creation and axe checks. Local browser uses available system Chromium through the isolated Playwright runner; CI installs the pinned Playwright Chromium. Local screenshot evidence is outside source at `/tmp/inkwell-phase5-search-{desktop,mobile}.png`. The connected browser runtime is not exposed here, so repository Playwright provides the authorized browser verification.

Intermediate failures were investigated rather than counted as passes: a refined Zod schema could not use `.omit` directly; a graph corruption test could accidentally leave an already-existing copy link unchanged; exact select-label matching was made explicit; a stale recovery message masked the cross-tab purge warning; and an expiry test read storage before asynchronous cleanup. These are corrected, with meaningful concurrency/purge tests retained.

Recovery is a browser buffer, not content history, offline synchronization or a backup. Seven-day expiry is enforced on access and pruned on resume/write; closed browsers cannot perform timed physical cleanup. At most 50 account/workspace/record slots of 64 KiB each are retained, with no silent capacity eviction. Same-origin scripts/browser-profile access can access the locally stored key; local encryption is not an XSS defense. A later verified session clears the previous partition. Browser storage/OS eviction can prevent recovery, and server sign-out still proceeds when storage is inaccessible.

Archives are version 1 structured text only (`assets: []`), up to 8 MiB and 10,000 archive rows. No attachments/remote asset retrieval, existing-project replacement, creative-content merging, server draft history, permanent deletion, snapshot sharing or AI generation is introduced. Matching workspace classification names are reused without rewriting existing labels. After a lost import response, check Projects before retrying to avoid a separate duplicate import.

Hosted migration locking/disk/backfill measurement, VPS search/performance, protected backup/restore rehearsal, SMTP/proxy/HTTPS/runtime grants, manual accessibility/Safari/PWA and release-scale validation remain Phase 7/approved staging gates. Standing owner merge approval does not authorize deployment, hosted migration/infrastructure, DNS, destructive operations, paid services or scope changes.
