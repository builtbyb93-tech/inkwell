## Evidence and intermediate corrections

Commands: `pnpm check`, `pnpm db:validate`, `pnpm test:integration`, `pnpm test:backup`, `pnpm test:e2e --workers=2`, `pnpm release:compose-check`, `pnpm security:secrets`, `pnpm audit --audit-level=low`. Tests use separate UUID databases and dedicated local storage. The backup project is separate from other SQL fixtures so their cleanup cannot invalidate a whole-database backup. Local scripted browser verification uses system Chromium through the isolated Playwright cache; CI installs pinned Chromium. The connected Browser automation tool is unavailable; the v0.6 directive explicitly authorizes repository Playwright.

The PWA checks use a normal temporary browser profile because Chrome correctly denies installation in incognito. Manifest icon dimensions, worker registration/scope, browser installability, accessibility-tree roles, exact three-item public cache, offline private navigation/API denial and authenticated reconnect all pass. The semantic/keyboard/axe/reflow checks cover light/dark themes and 200% text at 1280/390/320 CSS-pixel widths. A 320-pixel viewport also exercises 400%-equivalent reflow from 1280 pixels. Screenshots are outside source at `/tmp/inkwell-phase7-reflow-{desktop,mobile}.png`.

Intermediate failures were corrected rather than counted as passes: configuration-test replacement altered a username rather than its database; test selectors were aligned with real labels; browser incognito mode was replaced with a persistent test profile for installability; enlarged text exposed two-column dashboard cards that now reflow; HKDF buffers were made explicit; and an expected disposable-database disconnect was fenced during cleanup without suppressing unexpected failures or printing driver connection objects. Backup and runtime identities are tested separately. Generated local credential values were redacted from the initial cleanup diagnostic log; no production credential or private user content was used.

Runtime roles are not database row-level isolation: services still authorize every workspace and linked ID, and qualified FKs/guards enforce graph integrity. Backups contain private SQL and copied content; keep their keys outside the app, restrict scratch/key permissions and independently recover keys from an approved off-host destination. The 30-successful-UTC-date retention command is plan-only. Garage remains a single-node, one-app-replica profile with its previously documented conditional-write limits. Health/readiness and configuration syntax are not substitutes for a reviewed migration and actual staging acceptance.

The owner answered “Coolify” for hosted services. Coolify remains the chosen control plane; that answer does not establish a configured off-host destination or SMTP delivery service. Infrastructure access temporarily went offline and was restored by the owner; subsequent read-only discovery is recorded in the final handoff. Do not infer hosted success from this code report.
