## Behavior and integrity

ADR-007 records the closed five-kind concrete CanonRecord design and alternatives. Prisma maps to the existing Character SQL table, retaining every prior Character ID and conversion FK. Shared/local records are separate fixed-scope rows; overrides occupy a different table. SQL guards reject identity/type drift, incompatible endpoint pairs, wrong-story local endpoints and overrides against local bases. Conversion targets remain shared Characters. All private IDs and parents are workspace-qualified, including same-account cross-project cases.

Name and notes are independently inherited/custom/cleared. Relevant shared changes flag review; disjoint changes update inherited fields without discarding private story values. Override creation has an absence precondition; updates/reviews compare override and observed shared versions. Project locks serialize canonical writes and override/relationship races. Read models use consistent snapshots. Backlink endpoint summaries and override names are fetched together rather than per-edge document reads.

Shared archival preserves overrides/relationships. Custom or explicitly cleared story fields keep an archived base discoverable with a warning. Restore shared canon before editing its override; explicit review of existing conflicts remains permitted. Local records and edge archival are independent. No permanent creative deletion or automatic promotion exists.

UI contexts are explicit, route state is keyed by record/context, and pending inputs/editors are disabled. Shared changes require opening project canon. Stale saves preserve drafts. Refreshing comparison keeps the draft; discard is a separate explicit control. Review choices apply to saved values, so unsaved drafts must be explicitly discarded before reviewing. Converted Character overviews link into the Bible without losing Idea Vault provenance.
