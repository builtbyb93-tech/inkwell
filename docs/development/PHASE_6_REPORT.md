## Evidence and practical limits

Commands: `pnpm check`, `pnpm db:validate`, `pnpm test:integration`, `pnpm test:e2e --workers=2`, `pnpm security:secrets`, `pnpm audit --audit-level=high`, `pnpm audit --prod`, `pnpm storage:local`. Local Chromium is used through the isolated Playwright cache; CI installs pinned Chromium. CI results must be observed on the final published head.

The SQL suite covers selected effective canon, omission of hidden parent/provenance/source IDs, unchanged snapshots after source edits, integrity failures, unavailable storage and activation failure, uncertain activation acknowledgements, database immutability, token hashing, denied download, terminal revocation, expiry and revocation during storage reads, foreign scopes and paged authorization filters. Desktop/mobile sharing journeys cover owner selection/private preview, anonymous read-only access, exact permitted downloads, live-source independence, no private endpoint authority, revocation, expiration, no capability in network URLs, headers and axe checks.

Garage 2.5.0 does not enforce the S3 conditional write precondition in this local evaluation. A HEAD guard rejects known existing keys, but it is not atomic object lock. Server-only UUID keys are reserved in immutable SQL before one creation writer uploads them; READY snapshots have no replacement route. Every read verifies size/hash/schema. External corruption fails closed; lost activation acknowledgements do not delete committed READY payloads. A database outage can leave a private orphan requiring an explicitly approved maintenance procedure. No automated deletion is enabled.

Snapshot version 1 is structured text only (`assets: []`), maximum 1,000 selected records and 8 MiB, with up to 10,000 selected-endpoint relationships. No attachment feature or private asset URL is introduced. Separate links may have different expiry/download policies for the same immutable copy. Revocation stops future server access and the viewer periodically revalidates; it cannot erase content someone has already read or downloaded. The public fragment capability may remain in browser history/clipboard; it is not an account login.

Intermediate failures were fixed and rerun: cursor encoding and OR composition, provider conditional-write behavior, test-only Prisma transport typing, an ambiguous Next route-announcer alert selector, and omitted local Playwright cache configuration. Secret scanning initially flagged a prose API table as a generic-key pattern; the text was rewritten without weakening the scanner.

The owner approved 30 daily backups after protected off-host storage is configured. No hosted schedule, retention deletion or provisioning is activated. SMTP/TLS/proxy/runtime grants, hosted performance/backup restoration and staging approval remain release gates.

Configured review found that connection anchors replaced the share capability fragment. Connection buttons now focus and scroll to copied records without changing the URL. Desktop/mobile regression verifies keyboard and pointer movement, preserved URL, reload, page identity, screenshots and no page errors. Final rerun evidence is recorded in the owner handoff.

Initial GitHub browser CI exhausted the shared loopback CSRF limit. Account fixtures now honor the real Retry-After interval once with a bounded setup timeout; no application limit or proxy trust is weakened. Anonymous viewer contexts explicitly inherit each desktop/mobile viewport.
