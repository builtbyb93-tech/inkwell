# ADR-012 — Selected immutable copies and revocable capabilities

Status: accepted for the approved Phase 6 (#31–#33). Hosted activation remains separately gated.

A private snapshot is created from an explicit project/context selection, then previewed before issuing any public link. The title is explicit. Project/story details, Ideas, effective canon, scenes and groups are opt-in; active connections are a separate opt-in and include only selected endpoints. Source IDs are remapped. Unselected parent names, hidden canon base snapshots, taxonomy, revision/provenance history, private backlinks and private URLs are not traversed or appended. Story canon uses the selected story's effective values, including explicit clears, without modifying source canon. Selected scene ordering is normalized within the copy. The preview and permitted JSON download use the same closed `inkwell.snapshot` version 1 DTO. Technical bounds: 1,000 records, 10,000 selected connections, 8 MiB.

PostgreSQL stores qualified ownership and immutable payload identity/hash/size. Frozen JSON is stored in a private S3-compatible bucket through `packages/storage`; no content is fetched from live private records when serving a share. A PENDING row reserves a server-generated UUID/object key before the private write and verification. Only verified content becomes READY. Failed writes become FAILED and are cleaned when ownership/state can be confirmed. If activation acknowledgement is lost, cleanup cannot delete a READY object; uncertain database outcomes leave tracked private staging for an operator. S3 and PostgreSQL do not share a transaction.

Garage 2.5.0 is the tested local implementation from ADR-002, with AWS SDK 3.1168.0 (eligible under the package age gate), separate worktree buckets and keys. Put/get/delete, anonymous-read denial and denied bucket creation by the runtime key are verified. Garage did not honor conditional PutObject overwrite prevention in evaluation. The protocol therefore relies on unique database-reserved keys, one creation writer per snapshot, no READY payload update route, SQL immutable identity guards and verified hashes on every read. The adapter also refuses existing objects before writing; this check alone is not an atomic object lock. Tampered/missing payloads fail closed. No object URL or presigned capability is returned to clients. Hosted roles, TLS, privacy and backup/restoration still need approved deployment validation.

Each link has 32 random token bytes; only SHA-256 is stored. The raw link is shown once, with the token in `/share#token=…` so it does not enter server URL/access/referrer logs. Content/download requests send the token in a bounded POST body, require the configured Origin, and use independent database-backed global/IP rate limits. Native clients can supply the configured Origin. No cookie/session or edit permission is created by a share token. Owners choose expiry explicitly; no default retention is invented. Download permission and expiry are immutable per link; change policy by creating a new link and revoking the old one. Revocation is terminal and versioned.

Every view/download checks expiry, revocation and READY state before object I/O and again with a fresh database read afterward. It never returns 304 or a private storage URL. Responses forbid caching/indexing/referrers. The recipient UI revalidates on focus/visibility and periodically, and clears its rendering on expiry/failure. Already received text/downloads cannot be recalled or made uncopyable; download permission controls the provided export, not screenshots or manual copying.

The rich-text format has no attachments/images. The public asset manifest is explicitly empty; arbitrary asset references are rejected. The frozen JSON object is the first protected S3 payload. Future attachments require versioned selection/manifests and the same per-request policy proxy, rather than live/private source traversal. Project archive version 1 remains the core project graph; snapshots and operational share capabilities are separate and are not imported as live public links.
